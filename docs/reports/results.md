## 7. مقارنة الأداء بين المحركين (Python Batch vs. PySpark Benchmark)

| معيار المقارنة | محرك Python Streaming Batch | محرك Apache PySpark |
| :--- | :--- | :--- |
| **نطاق الاستخدام الأمثل** | الملفات الصغيرة والمتوسطة ($\le 200 \text{ MB}$) | الملفات الضخمة والعملاقة ($> 200 \text{ MB}$) |
| **استهلاك الذاكرة (Memory)** | ذاكرة ثابتة متناهية الصغر $O(1)$ | موزعة عبر الذاكرة العشوائية لـ JVM و RDDs |
| **زمن بدء التشغيل (Overhead)** | فوري وفائق السرعة (< 0.05 ثانية) | يحتاج لتهيئة SparkContext والـ JVM (~3-5 ثوانٍ) |
| **الإنتاجية (Throughput)** | **21,183 سجل / ثانية** في التحميل الخام | متوازية وقابلة للتوسع الأفقي عبر الـ Nodes |
| **معالجة البيانات غير النظيفة** | مرونة عالية في استيعاب التنوع اللغوي | حماية البيانات بـ `Explicit StructType Schema` |
| **سبب اعتماد التوجيه الهجين** | تجنب استهلاك موارد كبيرة للملفات الصغيرة | توزيع أعباء الحساب لملفات الـ 12.65 GB بالتوازي |
